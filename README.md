# Brasil nas urnas

Mapa interativo da apuração presidencial de 2026, com dados oficiais do TSE por estado.

**Acesse:** https://ian-wb.github.io/brasil-nas-urnas/

Página estática independente, com tema escuro, fotos oficiais dos candidatos e consulta direta ao TSE a cada 30 segundos enquanto aberta. Não exige login ou conta do ChatGPT, servidor próprio, chave de API ou compilação.

Resultados e fotos: Tribunal Superior Eleitoral. Malha dos estados: IBGE. Painel independente, sem vínculo com esses órgãos.

Os horários apresentados são os informados pelo TSE. O intervalo de consulta não altera a frequência de publicação ou o cache da fonte oficial. Em caso de falha, a página sinaliza a indisponibilidade e mantém a última consulta recebida enquanto estiver aberta.

Publicado no GitHub Pages a partir da branch main e da pasta raiz.
